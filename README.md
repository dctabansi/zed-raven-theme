# Raven Theme

A dark theme family for [Zed](https://zed.dev) combining the deep `#080909` surfaces of **One Dark Pro Max / Glass** with the syntax highlighting and UI accents of **JetBrains Islands Dark**.

## Variants

- **Raven Black** — Pitch-dark opaque background (`#080909`)
- **Raven Glass** — Translucent blurred background (`#080909DD`)
